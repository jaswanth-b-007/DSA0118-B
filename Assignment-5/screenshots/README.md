# Screenshots

The PNG files here are **hand-traced expected-output images**, clearly marked
"HAND-TRACED - NOT A REAL RUN SCREENSHOT". They are placeholders so the folder is not
empty and so you can see what the output should look like.

Before submission:

1. Compile and run each program with the commands in the root `README.md`.
2. Take a real terminal screenshot showing both the compile command and the output.
3. Replace these PNG files with those screenshots (keep the same names or add new ones).
4. Run the sanitizer commands and add the real reports here too.

Do not submit the placeholder images as if they were captured runs.
